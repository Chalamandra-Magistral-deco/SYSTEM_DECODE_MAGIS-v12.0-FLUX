## X / Y / NO

X = INPUT + CONTEXTO + EVIDENCIA

Y = CAPACIDAD + MODELO + RECURSOS

NO = BLOQUEADOR

La ejecución solo ocurre cuando:

X = válido
Y = resuelto
NO = vacío

## CONTROL ECONÓMICO

Toda operación debe poder responder:

- quién ejecutó
- qué capacidad utilizó
- qué modelo utilizó
- cuántos créditos consumió
- cuánto costó la IA
- cuánto ingreso produjo
- cuánto margen dejó
